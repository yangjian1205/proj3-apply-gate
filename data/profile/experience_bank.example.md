# 经历库（小卡片）

> `tailor` 改写时**从这里面挑最相关的卡片来重组**，而不是把整份简历从头到尾重写一遍。
> 每张卡片的字段固定：做了什么 / 用了什么 / 结果是什么 / 交付阶段。
> 「交付阶段」四选一：生产落地 / 内部试点 / 原型·技术验证 / 计划·估算 —— 它决定改写稿强度上限。

---

## card-001 · 企业知识库数据建设

- **做了什么**：制度 / FAQ / 产品手册等文档清洗后按主题切块，保留「所属文档 / 章节 / 原文链接」元数据，配增量同步
- **用了什么**：Python、文本清洗、切块策略、元数据设计
- **结果**：知识库与原始文档保持同步更新
- **交付阶段**：生产落地
- **出处**：resume.md「甲公司」第 1 条

## card-002 · 双路召回 + RRF 融合

- **做了什么**：先用 numpy 手写余弦相似度验证原理，再针对口语化提问与书面文档措辞不匹配的问题加入 BM25 关键词一路，用 RRF 融合排序
- **用了什么**：numpy、BM25、RRF、Chroma、text-embedding-v3
- **结果**：50 题评测集上向量 100% / BM25 93.3% / RRF 97.8%（块级 hit@5）
- **交付阶段**：生产落地（工作经历口径）/ 原型·技术验证（项目一口径，含自建语料）
- **出处**：resume.md「甲公司」第 3 条 + 项目一

## card-003 · 引用溯源 + 库外拒答

- **做了什么**：回答强制标注引用来源（文档名 + 原文链接），命中知识库外的问题走拒答分支
- **用了什么**：阈值路由、三档拒答
- **结果**：端到端库外拒答 5/5、可答题误拒 0/45
- **交付阶段**：生产落地 / 原型·技术验证
- **出处**：resume.md「甲公司」第 4 条 + 项目一

## card-004 · LangGraph 客服 Agent + interrupt 人审

- **做了什么**：StateGraph 建模客服状态机，SQLite checkpointer 做跨会话记忆；退款 / 改地址等敏感操作在工具执行前 interrupt 挂起，人工批准后恢复
- **用了什么**：LangGraph、Function Calling、SQLite checkpointer、FastAPI
- **结果**：跑通「低危全自动 / 高危必经人审」两条完整链路，会话重启可恢复、日志可回放
- **交付阶段**：原型·技术验证
- **出处**：resume.md 项目二

## card-005 · LLM 在线推理接口

- **做了什么**：基于 FastAPI 封装对话服务，支持流式输出与并发请求，对超时和失败请求做重试兜底；设计 Prompt 模板并管理多轮上下文
- **用了什么**：FastAPI、流式输出、重试兜底、Prompt 模板
- **结果**：保障调用稳定（无量化指标，面试前请准备具体案例）
- **交付阶段**：内部试点
- **出处**：resume.md「乙公司」第 1、2 条

## card-006 · 评测回归脚本

- **做了什么**：围绕真实业务问题搭建评测集，覆盖回答相关性与拒答准确率，写成评估脚本，每次改动跑回归
- **用了什么**：评测集设计、指标计算、回归流程
- **结果**：防止优化一项退化另一项
- **交付阶段**：内部试点
- **出处**：resume.md「乙公司」第 4 条 + 项目一

## card-007 · MCP 标准化接入 + 容器化

- **做了什么**：通过 langchain-mcp-adapters 接入自建 MCP Server，使工具可插拔；编写 Dockerfile 与 docker-compose.yml，密钥走 .env 注入
- **用了什么**：MCP 协议、langchain-mcp-adapters、Docker、docker-compose
- **结果**：新增 / 更换工具无需改业务代码；一条命令启动整套服务
- **交付阶段**：原型·技术验证（本机 Windows 环境 Docker 不可用，只交付静态产物）
- **出处**：resume.md 项目三

## 使用约定

1. **改写稿只能从卡片里取内容重组**，不许自己造句造事实
2. **交付阶段是强度上限**：`原型·技术验证` 的卡片，改写稿最多写到「完成流程 / 跑通链路 / 完成评测」，**不许出现「上线 / 生产环境 / 服务 N 用户」**
3. 卡片里没有的事实 → 不许出现在改写稿里（`provenance` 会拦）
